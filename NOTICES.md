# Source and generation provenance

The native spectrum implementation and support tools were created on 2026-10-01 with OpenAI Codex, GPT-6, for Jason Poindexter. They are AI-assisted code, manually reviewed by the same coding agent; no independent human code review or upstream acceptance is claimed. New C code and tools are GPL-2.0-or-later; see [COPYING](COPYING). No remote submission was performed.

The fixed-point radix-2 FFT is a small new implementation. It does **not** reuse Rockbox's plugin KISS FFT. The design uses conventional bit reversal, normalized radix-2 butterflies, a periodic Hann window, and separate-channel power. Constants are reproducibly generated by `tools/generate-tables.py`; the runtime uses integer arithmetic. This differs from the initial reuse proposal to avoid importing the plugin-only FFT build and API dependencies into the core. Numeric reference tests are in `tools/run-tests.py`.

The patch modifies GPL Rockbox source pinned to `e094c599fa60236527f9e272e0b8309d7696e399` (`v4.0-final`). Original upstream notices are preserved in the patched files. The source archive fingerprint is recorded in `tools/build.py` and the build manifests.

# ClassicSpectrum 1.3

Optional text-only Now Playing theme for the custom ipod6g spectrum firmware. The 280×70 visualizer retains the CrazyBitMono font/style, artist/title/album, playback/playlist indicators, battery, codec/bitrate, shuffle/repeat, volume, elapsed/progress/duration and Hold screen. Five approximate frequency labels appear below the spectrum.

Requires spectrum firmware 1.0.0 or newer, including the optional `%pF` presentation block and separately installed CrazyBitMono assets/fonts/icons/SBS. This independently versioned pack contains two runtime text files plus pack metadata. It is never added to the firmware ZIP. Version 1.3 explicitly selects the default dots and colors; metadata, labels and geometry are unchanged.

Build and install with `tools/theme-pack.py` from the repository root, then select ClassicSpectrum through Theme Settings. The installer checks dependencies, retains overwritten theme text for rollback, and leaves saved configuration and firmware untouched. See [theme guidance](../../docs/themes.md).
